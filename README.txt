النسخة السادسة — منصة متعددة الدعوات

الهدف:
دعوة واحدة لكل عروسين، ورابط مستقل لكل دعوة، ولوحة واحدة للمصمم.

مثال:
index.html?invite=jaafar-wedding
index.html?invite=ahmed-wedding

من admin.html:
- إنشاء دعوة جديدة
- تحديد slug
- تعديل البيانات
- نشر/إلغاء نشر
- معاينة الدعوة
- حذف الدعوة
- إدارة جميع الدعوات من مكان واحد

الإعداد:
1. أنشئ مشروع Supabase.
2. فعّل Email/Password Auth وأنشئ حساب المصمم.
3. نفّذ supabase_schema_v6.sql بعد وضع بريد المصمم مكان EMAIL_HERE.
4. ضع URL المشروع والمفتاح العام في config.js.
5. انشر الملفات على استضافة ثابتة.
6. شارك مع العميل رابط index.html?invite=slug فقط.
7. لا تشارك admin.html.

ملاحظة:
الموسيقى الحالية تعتمد على URL محفوظ في قاعدة البيانات. لاحقاً يمكن إضافة رفع الصور والموسيقى من لوحة المصمم إلى Supabase Storage مع سياسات وصول منفصلة.

مهم:
لا تضع Service Role Key داخل config.js أو أي ملف يرسل للمتصفح.
